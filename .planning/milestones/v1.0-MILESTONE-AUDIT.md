### Integration Gaps

**MISS-01: getAllResponseHeaders on Zotero.HTTP.request xmlhttp (Affects VERIFY-01)**
- Location: `utilities-translate-bundle.ts` ~line 21153
- Impact: Translators using the Translate-layer `request()` path (arXiv, reddit) throw `TypeError: xhr.getAllResponseHeaders is not a function`
- The fix exists in `translator-system-modern.ts` fakeXhr objects (for doGet/doPost) but was not applied to the `Zotero.HTTP.request` path in the bundled utilities

**MISS-02: XPath guard logic in Zotero.Utilities.xpath() (Affects VERIFY-01)**
- Location: `utilities-translate-bundle.ts` ~line 8292
- Guard: `!Zotero.isIE || 'evaluate' in rootDoc` — since `isIE` is always false, `!isIE` is always true, so the guard never actually checks for `evaluate` existence
- Impact: Wikipedia translator crashes with `TypeError: rootDoc.evaluate is not a function` when document lacks `.evaluate()`
