**Bug 1 — Unhandled rejection in getTranslatorObject (lines 805-852):**
Wrap every `callback(...)` invocation inside `getTranslatorObject` in its own `try { callback(...); } catch (_e) {}`. There are currently 3 bare `callback(...)` calls:
- Line 807: `callback({})` — wrap in try-catch
- Line 815: `callback({})` — wrap in try-catch
- Line 848: `callback(transObj)` — wrap in try-catch
- Line 851 (catch block): `callback({})` — wrap in try-catch

The resulting method should look like:
```typescript
async getTranslatorObject(callback: Function) {
  if (!translatorId || !executor.options.getTranslatorById) {
    try { callback({}); } catch (_e) {}
    return;
  }
  try {
    const embeddedTranslator = await executor.options.getTranslatorById(translatorId);
    if (!embeddedTranslator) {
      console.warn(`Embedded translator ${translatorId} not found`);
      try { callback({}); } catch (_e) {}
      return;
    }
    // ... existing sandbox and fn creation unchanged ...
    try { callback(transObj); } catch (_e) {}
  } catch (e) {
    console.error('Error in getTranslatorObject:', e);
    try { callback({}); } catch (_e) {}
  }
},
```

**Bug 2 — Missing DOMParser in Function context (lines 490-528, 555-596, 833-846):**
Add `'DOMParser'` as a parameter to ALL THREE `new Function(...)` calls and pass the resolved value as the corresponding argument.

For `detectWeb` (line 490): Add `'DOMParser'` after `'XPathResult'` in the parameter list. Add `dependencies?.DOMParser ?? (globalThis as any).DOMParser` after the `XPathResult` argument (line 527).

For `doWeb` (line 555): Add `'DOMParser'` after `'XPathResult'` in the parameter list. Add `dependencies?.DOMParser ?? (globalThis as any).DOMParser` after the `XPathResult` argument (line 595).

For the embedded translator Function in `getTranslatorObject` (line 833): Add `'DOMParser'` and `'XPathResult'` after `'requestDocument'` in the parameter list. Add `XPathResult` and `dependencies?.DOMParser ?? (globalThis as any).DOMParser` as corresponding arguments after the `requestDocument` arg (line 845). Note: the embedded translator Function currently lacks both `XPathResult` and `DOMParser` — add both.

The `dependencies` value is available via `this.options.dependencies` in `detectWeb`/`doWeb` methods. Inside `getTranslatorObject`, use `executor.options.dependencies` (since `executor` is the captured `this` reference).

**Bug 3 — dependencies spread override (lines 469-476):**
Change the constructor from:
```typescript
constructor(options: TranslatorExecutorOptions = {}) {
  this.options = {
    dependencies: {
      DOMParser: (globalThis as any).DOMParser,
    },
    ...options,
  };
}
```
To:
```typescript
constructor(options: TranslatorExecutorOptions = {}) {
  this.options = {
    ...options,
    dependencies: options.dependencies ?? {
      DOMParser: (globalThis as any).DOMParser,
    },
  };
}
```
This ensures `{ dependencies: undefined }` from `extractMetadata()` does not override the default.
