  <action>

    Add a `getAllResponseHeaders` method that forwards real headers from the fetch `response` object. The `response` variable is in scope (defined at line 21149).

    Replace the existing xmlhttp object (lines 21153-21159):
    ```typescript
    const xmlhttp = {
        status: response.status,
        responseURL: response.url,
        responseType: options.responseType || "",
        responseText: "",
        response: null,
    };
    ```

    With:
    ```typescript
    const xmlhttp = {
        status: response.status,
        responseURL: response.url,
        responseType: options.responseType || "",
        responseText: "",
        response: null,
        getAllResponseHeaders: () => {
            const parts: string[] = [];
            response.headers.forEach((value: string, key: string) => {
                parts.push(`${key}: ${value}`);
            });
            return parts.join('\r\n');
        },
    };
    ```

    This uses the higher-fidelity forwarding variant (not no-op) because the caller at line 10815 parses the header string into a `headers` object used by translators. Real headers provide better compatibility.
